## 简介

```
一句话中文需求 → 一份可直接下单的团餐采购清单。

【它解决什么】
行政/HR 每周订团餐的四个固定翻车点：
· 配比失衡 —— 小食买一堆、主食不够分
· 忌口遗漏 —— 有人不吃辣、有人素食、有人不吃牛肉
· 优惠浪费 —— 券躺在卡包里，结账才想起
· 预算失控 —— 心算人均，结账就超

【它是怎么算的】
把需求变成约束优化问题：
硬性忌口过滤候选餐品 → 多起点局部搜索求解 → 用麦当劳官方
calculate-price 接口回算真实总价 → 超预算自动削减并重新核价。
主食配额锁死为「每人一份」，这是唯一不允许打折的配額。

【实测数据】
· 14 人 / 480 元预算：应付 ¥475.00，主食正好 14 份
· 同一地址三家门店比价：最省 ¥285.50，比最贵省 ¥17.00
· 套餐营养拆解：素食场景人均热量从 38 kcal（不可用）修正到 459 kcal

【技术信息】
· 基于麦当劳中国 MCP Server（35 个工具）
· 8 个命令 · 176 项测试 · 零第三方依赖（纯 Python 标准库）
· 内置真实门店快照，完全离线也能复现
· 也是一个通用 Agent Skill（SKILL.md）

【重要说明】
本项目为第三方作品，非麦当劳官方产品。餐品价格、可售状态与
优惠券可用性以麦当劳官方渠道的实时结果为准；营养数据仅供参考，
不构成医疗或营养建议。

项目开源（MIT）：https://github.com/yschdxm/mcd-group-catering
顺手点个 Star 支持一下 ⭐
```

## 关于音乐（当前无音轨）

视频目前**没有音轨**。B 站允许静音视频，但完播率会受影响。三个选择：

1. **用 B 站创作中心的「音频替换」**：上传后在编辑页直接选平台曲库，最省事且不会有版权问题。
2. **本地加免版权 BGM**：用 ffmpeg 合并，例如
   `ffmpeg -i demo.mp4 -i bgm.mp3 -c:v copy -c:a aac -shortest out.mp4`
3. **暂时静音发布**：技术类内容静音也能看，靠画面与字幕传达信息。

当前成片的所有信息都已**烧进画面**，静音不影响理解。
